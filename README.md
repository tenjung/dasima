# 청정 동백 랜딩 페이지

동백다시마 앰플크림과 천연 동백오일을 소개하고 판매하는 랜딩 페이지입니다. 빌드가 필요 없는 정적 페이지라서 폴더를 그대로 Vercel이나 Netlify에 올리면 됩니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 페이지 본문: 오프닝 → CHAPTER 01 앰플크림 → 전환 띠 → CHAPTER 02 동백오일 → 함께 쓰는 루틴 → 후기 → 상품정보(제품별 탭)·FAQ |
| `styles.css` | 디자인. 챕터 색은 맨 위 `:root`의 `--cream-*`(동백 레드), `--oil-*`(골드·잎 녹색) 토큰에서 바꿉니다 |
| `config.js` | **구매 링크·가격·후기 설정 (운영 중에 주로 고치는 파일)** |
| `main.js` | 구매 버튼 연결, 가격·후기 표시, 꽃잎·스크롤 등장·숫자 카운트업, 고정 비주얼 전환, 챕터 탭, 상품정보 탭, 모바일 하단 구매바 |

움직임 효과는 라이브러리 없이 CSS와 기본 JS로 만들었습니다. 휴대폰이나 PC에서 '동작 줄이기'를 켠 사용자에게는 자동으로 꺼집니다.
| `images/` | 제품 사진: `cream-main`(튜브+패키지), `cream-texture`(크림 제형), `cream-stone`(돌 받침), `cream-hands`(손에 든 컷), `oil-main`(패키지+병, 흰 배경), `oil-mood`(테이블 무드컷), `oil-hand`(손에 든 병), `oil-set`(패키지+병 2개). 성분 사진(`ing-*`)과 ISO 마크만 기존 상세페이지에서 잘라 쓴 것입니다 |

## 운영 설정 (`config.js`)

- `links.cream`, `links.oil`: 판매처 상품 URL을 넣습니다. 비어 있으면 버튼이 "링크 준비 중"으로 비활성화됩니다. 버튼은 새 탭에서 열리고 `utm_*` 파라미터가 자동으로 붙습니다.
- `products.*.price`, `salePrice`: 숫자(원)를 넣으면 할인율과 함께 가격이 표시됩니다. 비워 두면 "가격은 판매처에서 확인해 주세요"가 표시됩니다.
- `contact.tel`: 푸터 문의 전화번호. 비우면 문의 전화 영역이 숨겨집니다.
- `reviews`: 게시 동의를 받은 실제 후기만 넣습니다. 비어 있으면 후기 섹션은 숨겨집니다.

## 공개 전 확인할 것

- 앰플크림 전성분: 상세페이지 이미지의 문구를 옮긴 것입니다. 이미지 속 "세라알마"처럼 성분명이 맞는지 의심되는 항목이 있으니 실제 패키지와 대조해 주세요.
- 이 페이지는 직접 판매하지 않는 브랜드 랜딩이라 판매사 상세 정보는 넣지 않고, 푸터·가격 안내·FAQ에 "온라인 공식 판매처: 데이세븐"만 밝힙니다. 푸터 문의 전화는 `config.js`의 `contact.tel`에서 바꾸며, 화면에만 그려지고 HTML 본문에는 번호가 없어 검색에 노출되지 않습니다. ㈜청정은 상품 정보의 책임판매업자 항목에만 "전라남도 여수시"로 표시합니다. 원본 이미지의 상세 주소가 서로 달라서입니다.
- 오일 사용기한: 기존 상세페이지의 "2026년 3월 7일"은 이미 지난 날짜여서 "제품 패키지에 별도 표기"로 바꿨습니다.
- 광고 문구: "화학성분 제로", "효능이 있는" 같은 표현은 쓰지 않았고, 기능성 문구는 미백·주름개선 범위에서만 "도움"으로 표현했습니다.
